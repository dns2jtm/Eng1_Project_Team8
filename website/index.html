Goose Patrol

A single-player 2D top-down libGDX game built for ENG1 (Cohort 2, Team 8). You play as a University of York student surrounded by hungry geese on campus: use items sensibly, watch out for hidden campus events, and disperse 8 geese before the 5-minute timer runs out.

Play the game

Runnable JAR with all dependencies included. Requires Java 17 or later.

Download JAR

Run with java -jar GoosePatrol.jar · all releases

How to play

KeyAction
ENTER / P / ESCStart, pause and resume (the game starts paused)
W A S D / arrow keysMove around campus
SPACEUse the selected item on all geese within range
1–9, Q / E / TABSelect an inventory item
R / ENTER (end screen)Play again (ESC to quit)
