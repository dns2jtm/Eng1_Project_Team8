Manual test cases

These cover the presentation layer (com.goosepatrol.screen), which needs a real window and keyboard and so can't be unit-tested. Run them on the released JAR and record the result, date and tester.

IDRequirementStepsExpected resultResult
MT-01FR_START_PAUSED, FR_PAUSE Launch the game. Wait 5 seconds. Press P. The start overlay ("Press P to start") is shown, the timer stays at 5:00 and geese don't move. After pressing P the overlay disappears and the timer starts counting down. Not yet run
MT-02FR_PAUSE During play, press ESC, wait, then press ESC again. Then click another application window and come back. "Paused" overlay shown; the timer stops and resumes from the same value. Losing window focus pauses the game automatically. Not yet run
MT-03FR_TIMER_EXPIRE Start the game and play without dispersing 8 geese until the timer runs out. The timer turns red below 1:00. At 0:00 the end screen shows "TIME'S UP!" with time played 5:00. Not yet run
MT-04FR_USE_ITEM, FR_GEESE_DISPERSE Let geese approach. Select Bread (key 1) and press SPACE with geese inside the range circle. Repeat with the Whistle (key 5). Bread: geese in range lose an orange hunger dot and stop to eat; full geese disappear and a "flew away" message is shown. Whistle: geese in range turn pale and run away, then return. The used item leaves the inventory bar. Not yet run
MT-05FR_ITEM_COUNTER Use two items and trigger one hidden event. The top bar shows "Items used: 2" and "Events triggered: 1". Not yet run
MT-06FR_EVENT_TRIGGER Look for the event locations before triggering them, then walk to the east of the lake (goose nest) and to the far right of the map (picnic basket). Nothing is visible before triggering. On triggering: a message appears (green for the picnic, red for the nest) and a coloured marker remains. The picnic adds 2 Bread; the nest spawns 3 geese. Not yet run
MT-07FR_WIN_CONDITION Disperse 8 geese before the timer runs out. On the end screen, press R. The end screen shows "YOU ESCAPED!" with the time played and statistics. R starts a new game in the paused state. Not yet run
MT-08Movement / map limits Move with WASD and with the arrow keys, including diagonally. Walk into a building, the lake and each edge of the map. Resize the window. The player moves smoothly and can't enter buildings, the lake or leave the map, sliding along walls. When resized, the game scales with black bars and the HUD stays readable. Not yet run
