Manual test cases

These check the screen and input behaviour that headless unit tests leave out: OpenGL drawing, keyboard controls and desktop execution. The underlying game logic is covered by the 88 automated JUnit 5 tests above.

IDRequirementsStepsExpected resultVerification status
MT-01FR_START_PAUSED, FR_PAUSE, FR_TIMER Launch the game. Wait 5 seconds. Press ENTER or P. The start card with the rules and controls is shown, the timer stays at 5:00 and geese do not move. After pressing ENTER or P, the card closes and the timer counts down. Logic automated · GUI checked
MT-02FR_PAUSE, QR_PAUSE_RESPONSE During play, press ESC, wait, then press ESC again. Then click another window and come back. Everything stops as soon as the key is pressed; the timer resumes from the same value. Losing window focus pauses the game automatically. Logic automated · GUI checked
MT-03FR_TIMER, FR_TIMER_EXPIRE, FR_END_SCREEN, QR_TIMER_ACCURACY Start the game and a stopwatch together. Avoid all hidden events and play without dispersing 8 geese until the timer runs out. The timer turns red below 1:00. At 0:00 the end screen shows "TIME'S UP!" with Time played: 5:00. The stopwatch reads 5:00 ± 1 s. Drift <0.05s automated · GUI checked
MT-04FR_INITIAL_INVENTORY, FR_USE_ITEM, FR_INVENTORY_DISPLAY, FR_GEESE_DISPERSE Check the inventory bar. Let geese approach. Select Bread (key 1) and press SPACE with geese inside the range circle. Repeat with the Whistle (key 5). The bar shows 4 Bread and 3 Whistles with the selected slot highlighted. Bread: geese in range lose an orange hunger dot and stop to eat crumbs; full geese leave with a "flew away" message. Whistle: geese in range turn pale blue and flee away for a few seconds before returning. Used items are removed from the bar. Logic automated · GUI checked
MT-05FR_ITEM_COUNTER, FR_EVENT_COUNTER Use two items and trigger one hidden event. The top bar shows "Items used: 2" and "Events triggered: 1". Counters automated · GUI checked
MT-06FR_EVENT_HIDDEN, FR_EVENT_TRIGGER, FR_EVENT_EFFECT, FR_EVENT_COUNT Inspect the campus before moving, then walk over all four event spots: on the path south-west of Campus Lake, by the east bank of Campus Lake, along the north walkway between Library and Computer Science, and on the east lawn between Computer Science and Dining Hall. Nothing is visible before stepping onto an event. Each event triggers once with a message and leaves a coloured circle with its name (green = positive, red = negative): Slippery Path (−15 s), Goose Nest (+3 geese), Lucky Shortcut (all geese flee), and Picnic Basket (+2 Bread). Effects automated · GUI checked
MT-07FR_WIN_CONDITION, FR_END_SCREEN Disperse 8 geese before the timer runs out. On the end screen, press R or ENTER. The end screen shows "YOU ESCAPED!" with time played and statistics. R or ENTER starts a new game in the paused state. Win summary automated · GUI checked
MT-08FR_PLAYER_MOVE, FR_MAP_BOUNDS, FR_CAMPUS_THEME, QR_INPUT_RESPONSE Move with WASD and arrow keys, including diagonally. Walk into a building, the lake and the outer campus edge. Resize the window. Movement starts straight away and feels smooth. Six named campus locations (five buildings and Campus Lake) are shown; the player cannot enter buildings, water or go past the map edge, and slides smoothly along walls. When resized, the view scales with letterbox bars. Bounds automated · GUI checked
MT-09QR_FRAME_RATE Run java -jar GoosePatrol.jar and play for 2 minutes while up to 9 geese are active on screen. Movement and animation stay smooth at 30 FPS or higher throughout. 60 FPS desktop · Lab PC check
MT-10QR_STABILITY, CR_EXECUTABLE, CR_JAVA On a Java 17+ machine, run java -jar GoosePatrol.jar and play three full sessions in a row (using R to restart). The JAR starts directly with no extra setup; no crashes or errors occur in any of the three sessions. Headless 3×5m pass · Lab PC check
