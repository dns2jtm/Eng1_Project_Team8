Testing approach

  • Unit tests (JUnit 5) for the logic, entity, item and event packages. These contain no rendering code, so they run without a window.
  • Integration smoke test using the libGDX headless backend. It plays complete 5-minute sessions on the libGDX application thread.
  • Traceability: test names include requirement IDs, e.g. FR_PAUSE: nothing updates while paused. See the traceability matrix.
  • Manual tests for the presentation layer (drawing, HUD, keyboard input).
